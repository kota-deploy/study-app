# 学習ノート

自分専用の学習Webアプリです。第1弾は「簿記・会計」（日商簿記3級を中心に、財務諸表分析と連結会計の入口まで、6週間）。

- ビルド不要。`index.html` をダブルクリックで開くだけで動きます（file://）。
- 学習記録はブラウザの localStorage（キー `studyApp`）に保存します。
- スマホ（幅400px）とPCの両方、ライト/ダーク（OS設定に追従）に対応しています。
- GitHub Pages に公開すると、スマホのホーム画面にアイコンとして追加でき、オフラインでも開けます（PWA）。
- 公開版は、開くと最初にログイン画面（メールアドレスとパスワード）が出て、ログインするまで中身を表示しません。
- Supabase（無料）を設定すると、PCとスマホで進捗を自動同期します。設定手順は [docs/PHASE2_SETUP.md](docs/PHASE2_SETUP.md)。
- 外部への通信は、同期を設定したときの Supabase（API と、版を固定したライブラリ）だけです。

## 画面

| 画面 | 内容 |
|---|---|
| ホーム | コース一覧と「コースを追加」 |
| コースのホーム | 今日のタスク、今週の進捗率、連続学習日数、復習待ち、受験予定日までの残り日数、未学習の項目数 |
| 学習計画 | 6週間。タスクのチェック・編集・追加・削除、学習時間（分）、メモ |
| 解説 | 週・分野で絞り込み。一言で → 図解 → しくみ → 例 → よくある間違い → 仕事とのつながり → 出典 |
| ドリル | 仕訳（複数行・自動採点）、計算、選択。順番・ランダム・復習待ちだけ |
| カード | Leitner方式（箱1〜5）。分かった／あいまい／分からない |
| 成績・復習 | 正答率の推移、間違いの多い分野、復習キュー、カードの箱 |
| 出典一覧 | 資料ごとの参照件数、設定データの数値、要確認・級未確認の一覧 |
| 設定 | 受験予定日、JSONの書き出し・読み込み、全データ削除 |

## 受験予定日と版

- 未設定: 両方の版を表示し、版で違う項目に「2022版のみ」「2027版のみ」のバッジ。
- 2027-03-31以前: 2022年度版。2027版のみの項目は「対象外」（出題・復習しない）。
- 2027-04-01以降: 2027年度版。2022版のみの項目は「対象外」。
- 切り替えは `courses/boki/config.js` の `editions` と各項目の `appliesTo` だけで決まります。

差分の詳細は [docs/edition-diff.md](docs/edition-diff.md)。

## テスト

```
node tests/run-all.js
node tests/validate-data.js
```

## フォルダ構成

```
index.html            起動ファイル（script タグの順に読み込む）
manifest.webmanifest  ホーム画面アプリの情報
sw.js                 オフライン用の Service Worker
icons/                アプリのアイコン
css/app.css           スタイル（CSS変数でライト/ダーク）
js/core/              画面に依存しない処理（保存、版、間隔反復、採点、集計、同期の統合）
js/sync.js            Supabase との同期とログイン
js/pwa.js             ホーム画面アプリの登録
js/views/             各画面
js/app.js             起動とルーティング
config.example.js     同期の設定のひな形（config.js にコピー。リポジトリには入れない）
supabase/schema.sql   テーブルと RLS のポリシー
scripts/build-site.js GitHub Pages 用に _site/ を作る
.github/workflows/    GitHub Actions（テスト → 公開）
courses/registry.js   コースの登録
courses/boki/         簿記コースのデータ（出典、設定、勘定科目、計画、解説、問題、カード）
courses/_template/    新しいコースのひな形（docs/ADD_COURSE.md）
tests/                検証スクリプトと単体テスト
```
