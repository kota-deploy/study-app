# Phase 2: ログイン・同期・スマホのホーム画面アプリの設定手順

すべて無料枠で使えます。所要時間は30〜40分ほどです。画面の名前は2026年10月時点のものです。名前が少し違う場合は、近い名前のメニューを選んでください。

公開したサイトは、**開くと最初にログイン画面が出て、ログインするまで中身（学習記録を含む）を表示しません。** パスワードは、手順 2-4 であなたが自分で決めます。パスワードはこの手順書にもチャットにも書かず、パスワード管理ツールなどに保存してください。

全体の流れ:

1. GitHub に公開する（スマホから開ける https のURLを作る）
2. Supabase でデータベースと、あなた専用のアカウントを用意する
3. GitHub に Supabase の接続情報を登録して、公開し直す
4. スマホのホーム画面に追加して、ログインする

---

## 1. GitHub に公開する

1. https://github.com にログインし、右上の「＋」→「New repository」を押す。
2. Repository name に `study-app` と入力する。
3. 「Public」を選ぶ（無料で GitHub Pages を使うには公開リポジトリが必要です。リポジトリに入るのはアプリのコードと一般的な簿記の内容だけで、学習記録やパスワードは入りません）。
4. 「Add a README」などのチェックは付けずに、「Create repository」を押す。
5. このフォルダをそのリポジトリに push する（Claude に頼むか、画面に表示されるコマンドを実行する）。
6. リポジトリの「Settings」→ 左の「Pages」を開く。
7. 「Build and deployment」の「Source」で「GitHub Actions」を選ぶ。
8. 上の「Actions」タブを開き、「Deploy to GitHub Pages」が緑のチェックになるまで待つ（2分ほど）。
9. 「Settings」→「Pages」に表示される URL（例: `https://ユーザー名.github.io/study-app/`）を控える。この時点で開くと、ログイン画面に「ログインの準備ができていません」と出ます（中身は表示されません）。

## 2. Supabase を用意する

### 2-1. プロジェクトを作る

1. https://supabase.com を開き、「Start your project」からサインアップする（GitHub アカウントでも可）。
2. 「New project」を押す。
3. Name に `study-app`、Database Password に長いパスワード（「Generate a password」で自動作成）を入れる。これはデータベースの管理用で、アプリのログインには使いません。パスワード管理ツールに保存する。
4. Region は「Northeast Asia (Tokyo)」を選ぶ。
5. 「Security」の欄は次のようにする。
   - Enable Data API: **オン**（アプリはこの API で読み書きする）
   - Automatically expose new tables: **オフ**（必要な権限は `schema.sql` で明示的に与える）
   - Enable automatic RLS: **オン**
6. Plan が「Free」であることを確かめて、「Create new project」を押す。準備が終わるまで2分ほど待つ。

### 2-2. テーブルと権限を作る

1. 左のメニューの「SQL Editor」を開く。
2. 「New query」を押す。
3. このフォルダの `supabase/schema.sql` の中身をすべて貼り付ける。
4. 右下の「Run」を押す。「Success. No rows returned」と出れば成功。
5. 左の「Table Editor」で `user_state` を開き、「RLS enabled」（または鍵のアイコン）が表示されていることを確かめる。

### 2-3. 接続情報を控える

1. 左下の「Project Settings」（歯車）→「API Keys」（または「Data API」）を開く。
2. 「Project URL」（`https://xxxx.supabase.co`）を控える。
3. 「anon」または「publishable」と書かれたキーを控える。
4. **「service_role」「secret」と書かれたキーは使いません。** どこにも貼らないでください（公開用のビルドは、誤って入れると止まるようにしてあります）。

### 2-4. あなた専用のアカウントを作る（ここでパスワードを決める）

1. 左の「Authentication」→「Users」を開く。
2. 「Add user」→「Create new user」を押す。
3. Email にあなたのメールアドレス、Password に**あなたが決めたパスワード**を入れる。12文字以上で、ほかのサービスと同じでないものにしてください。
4. 「Auto Confirm User」にチェックを入れて、「Create user」を押す。
5. 「Authentication」→「Sign In / Providers」を開き、「Email」が有効になっていることを確かめる。
6. 同じ画面の「Allow new users to sign up」を**オフ**にして「Save」。これで、あなた以外はアカウントを作れません。

パスワードはあとから、アプリの「設定」→「パスワードを変える」でも変えられます。

### 2-5. パスワードを忘れたときのための設定

パスワードを忘れたときは、メールのリンクでログインできるようにします。

1. 「Authentication」→「URL Configuration」を開く。
2. 「Site URL」に、1-9 で控えた GitHub Pages の URL を入れて「Save」。
3. 「Redirect URLs」の「Add URL」で、同じ URL を追加して「Save」。

メールの本文は、Supabase 標準のまま（「Your sign-in link」）で使います。標準のメール送信では本文を編集できません（編集には独自の SMTP の設定が必要）。

パスワードを忘れたときの流れ:

1. Safari や Chrome などのブラウザで公開 URL を開く（ホーム画面のアプリではなく）。
2. ログイン画面の「パスワードを忘れた場合」から、メールを送る。
3. 届いたメールの「Sign in」リンクを、同じブラウザで開く。これでログインできる。
4. 「設定」→「パスワードを変える」で新しいパスワードにする。
5. ホーム画面のアプリでは、新しいパスワードでログインする。

## 3. GitHub に接続情報を登録する

1. GitHub のリポジトリの「Settings」→「Secrets and variables」→「Actions」を開く。
2. 「Variables」タブ →「New repository variable」で、次の3つを登録する。
   - `SUPABASE_URL`: 2-3 の Project URL
   - `SUPABASE_ANON_KEY`: 2-3 の anon（publishable）キー
   - `SITE_URL`: 1-9 の GitHub Pages の URL
3. 「Actions」タブ →「Deploy to GitHub Pages」→「Run workflow」を押して、公開し直す。
4. 公開された URL を開き、メールアドレスとパスワードの入力欄があるログイン画面が出れば成功。

## 4. スマホのホーム画面に追加して、ログインする

### iPhone

1. Safari で公開 URL を開く。
2. 下の共有ボタン（四角から上向きの矢印）→「ホーム画面に追加」→「追加」。
3. ホーム画面の「学習ノート」アイコンから開く。
4. メールアドレスとパスワードを入れて「ログイン」。右上が「同期済み」になれば完了。

### Android

1. Chrome で公開 URL を開く。
2. メニュー（︙）→「ホーム画面に追加」（または「アプリをインストール」）。
3. あとは iPhone の 3〜4 と同じ。

### PC

1. ブラウザで公開 URL を開き、同じメールアドレスとパスワードでログインする。
2. Chrome や Edge では、アドレスバーのインストールボタンで、PC にもアプリとして置けます。

一度ログインした端末は、ログアウトするまでログインしたままです。毎回パスワードを入れる必要はありません。

## 5. いままでの記録を移す（ファイルを直接開いて使っていた場合）

ファイル（file://）で開いた版と、公開 URL の版は、ブラウザの保存場所が別です。

1. ファイルで開いた版の「設定」→「JSONを書き出す」。
2. 公開 URL の版でログインし、「設定」→「JSONを読み込む」でそのファイルを選ぶ。
3. 自動で同期され、スマホにも反映されます。

## 知っておくこと

- **守られる範囲:** ログインで守られるのは、あなたの学習記録です。アプリのコードと教材（一般的な簿記の解説・問題）は公開リポジトリにあるので、リポジトリを見れば誰でも読めます。
- **オフライン:** 一度ログインした端末は、オフラインでも開いて学習できます。オンラインに戻ると自動で同期します。
- **ログアウト:** ログアウトすると、次に開いたときにログイン画面が出ます。その端末の学習記録は消えずに残ります（他人と共用する端末では、「設定」→「全データを削除する」も使ってください。全削除は同期先からも消えるので注意）。
- **競合**: 同じ日の計画や同じカードを2台で変えた場合は、あとから変えた方が残ります。ドリルの記録は両方とも残ります。
- Supabase の無料プランは、**1週間使わないとプロジェクトが一時停止**することがあります。停止中は新しくログインできませんが、ログイン済みの端末では学習を続けられます。Supabase の画面で「Restore」を押すと再開します。
- Supabase 標準のメール送信は、**1時間あたりの送信数に上限**があります。確認コードが届かないときは、しばらく待ってから送り直してください。
- アプリの新しい版を公開すると、次に開いたときに「新しい版があります」と表示されます。「更新する」を押すと切り替わります。
- ファイル（file://）で直接開く場合は、`config.js` を置かなければ、ログインなしで今までどおり使えます。
